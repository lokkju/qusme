How it works

  1. 1

    Install the extension

    Add qus.me to Chrome or Firefox. It asks for no access to any site: it touches a page only when you press Alt+Q, click Insert or use the right-click menu on that page.

  2. 2

    Create your queue

    Pick a passphrase. The extension makes your queue's key on this device, locks it with that passphrase and shows you a 12-word recovery code once, with a recovery sheet you can save. Write the code down: it, or a device you've already set up, is the only way onto a new device.

  3. 3

    Connect your agent

    Add https://app.qus.me/mcp to your AI app (Claude or another MCP client). Your agent shows a short code; type it into the extension, then choose which accounts it may draft for and how many drafts it may add per day, week or month. Each agent you connect gets its own approval.

  4. 4

    Insert and post

    On X, Bluesky, Mastodon or LinkedIn, click into the post box and press Alt+Q. Pick a draft, read it, change what you like and click Post. The site gets a post you typed; the picker only fills the box.

Nobody else can read your queue

Encrypted before it leaves your device

Each draft is encrypted on your device with a key only your devices hold, then stored on public Nostr relays (servers anyone can use to pass messages along). A relay holds data it can't open.

An agent sees only what it wrote

An approved agent drops drafts into your queue through app.qus.me. It can't list the queue, read your other drafts or see what you posted. You set its accounts and its limit, and you can revoke it from the popup.

No tracking

No analytics, no ads, no selling your data. app.qus.me sees an agent's draft only while it checks and encrypts it, then forgets it, and it never holds the key to your queue.

Questions

Does qus.me post for me?

No. It puts the draft you pick into the post box, the same as if you had pasted it. You read it, edit it and click Post. There is no setting that posts for you.

Can the agent read my drafts?

No. An agent sends drafts in through app.qus.me, which encrypts each one to your queue. Neither the agent nor app.qus.me holds the key that opens the queue, so neither can read it; the agent sees only what it wrote.

Which agents work?

Anything that speaks MCP over HTTP: the Claude apps, Claude Code and other MCP clients. Each one gets its own approval, its own accounts and its own limit, and you can revoke any of them on its own.

What sites work?

X, Bluesky, Mastodon and LinkedIn come built in; for Mastodon you give your server's address. You can add another site yourself as a destination, and Alt+Q opens the picker in whatever field you're typing in.

What if I lose my device?

Enter your 12-word recovery code, or paste the recovery sheet, on the new device; or pair it from another device you already set up. Without the code and without another device the queue is gone: nobody else holds its key, us included.

Can I run the MCP server myself?

Yes. Run npx @qusme/mcp on your own computer and add it to Claude Desktop, Claude Code or any MCP client that starts local servers. It shows a short code; type it into the extension like any other. Your agent's drafts then go from your computer straight to your queue, without app.qus.me. The local server is free. The hosted one at app.qus.me is free while in beta and may become paid later.

What does it cost?

Nothing while it's in beta.

How it's built

Your queue is a Nostr key pair, made in the extension and never sent anywhere. Drafts are encrypted end to end and published to Nostr relays, which hold only ciphertext. Agents reach the queue through the MCP server at app.qus.me after you approve them over OAuth; the server seals each draft to your queue's inbox and holds no key that opens the queue. The code is open source on GitHub.
